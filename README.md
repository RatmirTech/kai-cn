# kai-cn

## Структура проекта

- `src/` — исходники Turbo Pascal и ассемблерная обвязка IPX/SPX.
- `docs/OPISANIE.MD` — подробное описание программ и используемых вызовов.

## Как запускать

Эти программы предназначены для DOS и используют драйверы IPX/SPX и
NetBIOS. В современной macOS/Linux/Windows-среде напрямую они не запускаются.
Используйте реальную DOS-систему или эмулятор DOS, например DOSBox-X, с
настроенным IPX/SPX-совместимым сетевым драйвером.

### Подготовка

1. Установите Turbo Pascal 7.0 или совместимый 16-битный компилятор и
   ассемблер Turbo Assembler/MASM.
2. Запустите DOS-окружение и перейдите в каталог `src`:

   ```dos
   C:
   CD \KAI-CN\SRC
   ```

3. Соберите ассемблерный модуль:

   ```dos
   TASM IPX.ASM
   ```

   В результате должен появиться файл `IPX.OBJ`.

4. Скомпилируйте Pascal-программы. Каждая из них использует `IPX.OBJ`,
   поэтому объектный файл должен находиться рядом с исходниками:

   ```dos
   TURBO SPX_C.PAS
   TURBO GATEWAY.PAS
   TURBO NETBIOS_DG_S.PAS
   TURBO NETBIOS_CN_S.PAS
   ```

   Если компилятор запускается из командной строки, используйте эквивалентные
   команды своего Turbo Pascal (`TPC`, `TPX` или сборка из IDE).

### Запуск

Нужны как минимум два DOS-узла с доступными IPX/SPX и NetBIOS:

1. На узле шлюза запустите `GATEWAY.EXE`.
2. На отдельном узле запустите `NETBIOS_DG_S.EXE` — сервер NetBIOS-датаграмм.
3. На другом узле запустите `NETBIOS_CN_S.EXE` — сервер NetBIOS-сеанса.
4. На клиентском узле запустите `SPX_C.EXE`.
5. В `SPX_C` введите IPX-сеть и IPX-узел шлюза, когда программа запросит
   эти значения.
6. Вводите сообщения в клиенте. Сообщение `exit` завершает соединение.

IPX-адреса, имена NetBIOS и номера сокетов должны быть согласованы между
узлами. Если DOSBox не предоставляет сетевой драйвер с нужными IPX/SPX и
NetBIOS-вызовами, программы не смогут работать только за счёт запуска
эмулятора — потребуется настроить соответствующую сетевую среду.
